# ژورنال طهان — کرنل آریا

ژورنال معاملاتی دسکتاپ: آفلاین-فرست، فارسی، راست‌به‌چپ، امن و قابل توسعه.

## معماری

- **کرنل:** Rust + Tauri 2 با معماری موتوری ماژولار (۱۰ کریت در ۵ سطح وابستگی)
- **ذخیره‌سازی:** SQLite رمزنگاری‌شده (سازگار با SQLCipher)
- **رابط کاربری:** React 18 + TypeScript strict + Vite + Tailwind CSS + فونت Vazirmatn
- **پلاگین‌ها:** فرایند جداگانه با JSON-RPC 2.0 روی stdio؛ پلاگین‌های پایتونی با venv اختصاصی

## ساختار

```
tahan-journal/
├── Cargo.toml                  # ورک‌اسپیس Rust
├── package.json                # اسکریپت‌های ریشه
├── crates/                     # ۱۰ کریت موتوری (سطح ۰ تا ۴)
├── apps/tahan-desktop/         # اپلیکیشن Tauri 2
├── frontend/                   # رابط کاربری React
├── docs/                       # مستندات، قراردادها و ردیابی
├── plugins/                    # پلاگین‌های رسمی و پایتونی
├── scripts/                    # اسکریپت‌های توسعه
└── tests/                      # تست‌های یکپارچه
```

## شروع سریع

```powershell
npm run dev:frontend   # سرور توسعه فرانت‌اند (پورت 5173)
npm run dev:backend    # بررسی کرنل با cargo check
npm run test:all       # تست کرنل و بیلد فرانت‌اند
npm run lint:all       # کنترل کیفیت (rustfmt، clippy، ESLint)
npm run format:all     # قالب‌بندی کل پروژه
```

## فازها

فاز ۰ (آماده‌سازی مخزن و خط پایه فناوری) تکمیل‌شده است.
ردیابی فازهای ۱.۱ تا ۵.۵ در [docs/phases/README.md](docs/phases/README.md) انجام می‌شود.

## اصول هسته‌ای

- آفلاین-فرست: هیچ داده کاربری به سرور خارجی ارسال نمی‌شود.
- فارسی و راست‌به‌چپ خدمات هسته‌ای هستند.
- فیلدهای سفارشی شهروند درجه‌یک هستند.
- قراردادهای عمومی منبع حقیقت هستند و نسخه‌بندی می‌شوند.
- پلاگین‌ها فقط از طریق سرویس‌های رسمی کرنل ارتباط برقرار می‌کنند.
