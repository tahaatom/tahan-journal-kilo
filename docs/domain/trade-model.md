# مدل داده معاملاتی

> وضعیت: فاز ۰ — ساختار اولیه.

## موجودیت‌های اصلی

Profile، TradingAccount، Symbol، JournalTrade، EntryLeg، ExitLeg، Execution، SourceRecord، ManualOverride، PositionGroup (رزرو شده)

## لایه‌های داده

داده خام → داده کانونیک → دفتر بازنویسی → داده مؤثر → پیش‌نمایش تحلیلی

## قوانین هسته‌ای

- داده خام غیرقابل تغییر است.
- تصحیحات دستی در دفتر بازنویسی ردیابی می‌شوند.
- داده مؤثر از کانونیک و دفتر بازنویسی مشتق می‌شود.
