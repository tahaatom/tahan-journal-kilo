# مدل واردات

> وضعیت: فاز ۰ — ساختار اولیه. پیاده‌سازی در فاز ۱.۱۵.

## جریان

فایل بروکر → SourceRecord (غیرقابل تغییر، هش‌دار) → Execution → تخصیص به Leg

## قوانین

- داده خام وارداتی غیرقابل تغییر است.
- هش فایل و متادیتا دسته واردات ثبت می‌شود.
- تشخیص تکراری بر اساس هش، تیکت، زمان، نماد، حجم و قیمت.
- رکوردهای بدون تخصیص needs_assignment علامت‌گذاری می‌شوند.
