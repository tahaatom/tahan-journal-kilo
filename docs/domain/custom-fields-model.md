# مدل فیلدهای سفارشی

> وضعیت: فاز ۰ — ساختار اولیه. پیاده‌سازی در فاز ۱.۵.

## اصل

فیلدهای سفارشی شهروند درجه‌یک هستند: در فرم‌ها، فیلترها، لیست‌ها، داشبورد، آمار و بینش‌های آینده قابل استفاده‌اند.

## انواع ذخیره‌سازی نسخه ۱

Text، LongText، Integer، Decimal، Boolean، DateTime، Enum، MultiEnum، Rating، TagSet

## انواع معنایی نسخه ۱

short_text، long_text، number، price، percent، money، datetime، boolean، single_select، multi_select، rating، tag
