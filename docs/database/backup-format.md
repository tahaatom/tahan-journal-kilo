# فرمت پشتیبان

> وضعیت: فاز ۰ — ساختار اولیه. پیاده‌سازی در فاز ۱.۱۶.

## ساختار بسته

- manifest.json
- اسنپ‌شات دیتابیس رمزنگاری‌شده
- پوشه پیوست‌ها
- checksums.json
- اسنپ‌شات تنظیمات (اختیاری)
- format_version

## اصول

- فشرده‌سازی zstd، رمزنگاری AES-GCM
- هش blake3 برای همه فایل‌ها
- هیچ دیتابیس متنی در بسته پشتیبان نیست
