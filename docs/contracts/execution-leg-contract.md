# قرارداد اجرا و لگ

> وضعیت: فاز ۰ — خلاصه. پیاده‌سازی در فاز ۱.۶.

## تعریف‌ها

- **Execution**: بُرد واقعی بروکر
- **Entry Leg**: رویداد معنایی ورود
- **Exit Leg**: رویداد معنایی خروج
- هر Leg می‌تواند یک یا چند Execution داشته باشد
- هر Execution دقیقاً به یک Leg تعلق دارد

## قوانین

- معاملات دستی باید Execution دستی بسازند
- داده‌های وارداتی ابتدا SourceRecord، سپس Execution و سپس تخصیص به Leg می‌شوند
- Execution‌های تخصیص‌نیافته با needs_assignment علامت‌گذاری می‌شوند
- Execution‌های تخصیص‌نیافته در PnL یا محاسبه R استفاده نمی‌شوند
