# کدهای خطا

> وضعیت: فاز ۰ — ساختار اولیه. محدوده‌های نهایی در فاز ۱.۲ تثبیت می‌شوند.

## محدوده‌های پیشنهادی به تفکیک موتور

| موتور | محدوده |
|---|---|
| foundation | 1000–1999 |
| storage | 2000–2999 |
| security | 3000–3999 |
| schema | 4000–4999 |
| domain | 5000–5999 |
| plugin | 6000–6999 |
| runtime | 7000–7999 |
| query | 8000–8999 |

## ساختار خطا

- کد عددی یکتا
- نام متغیر قابل‌خواندن ماشینی
- کلید پیام فارسی قابل‌خواندن برای کاربر
- متنیان اختیاری

## قوانین

- هر کد عددی دقیقاً به یک خطا تعلق دارد.
- anyhow فقط در مرزهای اپلیکیشن استفاده می‌شود، نه در API عمومی موتورها.
