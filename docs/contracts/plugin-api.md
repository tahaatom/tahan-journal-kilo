# قرارداد API پلاگین

> وضعیت: فاز ۰ — ساختار اولیه. تعریف کامل در فاز ۱.۲.

## پروتکل

- JSON-RPC 2.0 روی stdio با پیام‌های خط‌محور
- حداکثر اندازه پیام: ۱۰ مگابایت
- تایم‌اوت پیش‌فرض: ۳۰ ثانیه
- احراز هویت با نشانه نشست

## ساختار پیام

- درخواست: `jsonrpc`، `id`، `method`، `params`
- پاسخ: `jsonrpc`، `id`، `result`
- خطا: `jsonrpc`، `id`، `error` (با `code`، `message`، `data`)

## قوانین

- متدهای ناشناخته رد می‌شوند.
- مجوزها به‌ازای هر متد اجرا می‌شوند.
- پلاگین فقط از طریق سرویس‌های رسمی کرنل به داده دسترسی می‌یابد.
