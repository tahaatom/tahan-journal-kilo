# قرارداد دستور (Command Envelope)

> وضعیت: فاز ۰ — ساختار اولیه. تعریف کامل در فاز ۱.۲.

## ساختار پیشنهادی

- `command_id`: شناسه یکتای دستور (UUID v4)
- `command_type`: نوع دستور
- `payload`: بار دستور
- `issuer`: صادرکننده
- `timestamp`: زمان UTC (ISO 8601)
- `correlation_id`: شناسه همبستگی

## قوانین

- دستورات از طریق IPC امن Tauri صادر می‌شوند.
- دستورات اتمیک هستند.
- هر دستور پس از اجرای موفق، رویدادهای دامنه‌ای منتشر می‌کند.
