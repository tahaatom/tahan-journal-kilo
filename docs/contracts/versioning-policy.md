# سیاست نسخه‌بندی

> وضعیت: فاز ۰ — ساختار اولیه. تعریف کامل در فاز ۱.۲.

## نسخه‌ها

- نسخه قرارداد کرنل (kernel contract version)
- نسخه API پلاگین (plugin API version)
- نسخه اسکیمای دیتابیس (database schema version)
- نسخه فرمت پشتیبان (backup format version)

## سیاست رویدادها

- رویدادها نسخه‌بندی می‌شوند.
- تغییر شکست‌زا بدون سیاست منقضی‌سازی صریح ممنوع است.
- مصرف‌کننده‌ها باید به نسخه‌های قبلی تا مدت منقضی‌سازی پشتیبانی کنند.
