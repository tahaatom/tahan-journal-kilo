# قرارداد محاسبه R

> وضعیت: فاز ۱.۲ — تثبیت‌شده.
> پیاده‌سازی: فاز ۱.۶ (موتور دامنه، `aria-domain-engine`)

## تعریف

**R** واحد ریسک اولیه پذیرفته‌شده است.

## خروجی‌های محاسبه

| خروجی | تعریف |
|---|---|
| `PlannedR` | R برنامه‌ریزی‌شده در زمان ورود (بر اساس حد ضرر اولیه و حجم) |
| `InitialRiskPriceDistance` | فاصله قیمتی بین قیمت ورود میانگین وزنی و حد ضرر اولیه |
| `InitialRiskAmount` | ریسک اولیه به واحد پول = `InitialRiskPriceDistance × حجم` |
| `RealizedPnL` | سود/زیان تحقق‌یافته خالص (کمیسیون و سواپ کسر شده) |
| `RealizedR` | `RealizedPnL ÷ InitialRiskAmount` |
| `ExitLegR` | R مربوط به یک Exit Leg (اختیاری، به‌ازای هر خروج) |
| `TradeR` | R کل معامله بر مبنای نتیجه کل |
| `RiskCalculationStatus` | وضعیت محاسبه (مثلاً `ok`، `no_stop_loss`) |
| `RiskBasis` | مبنای ریسک: `stop_loss` یا `manual_risk` |

## قوانین

- چند ورودی: قیمت ورود **میانگین وزنی حجم**
- **حد ضرر اولیه** (initial stop loss) مبنای ریسک است
- جابه‌جایی حد ضرر بعداً **مبنای R اولیه را تغییر نمی‌دهد**
- بدون حد ضرر: `RiskCalculationStatus = no_stop_loss` و R خودکار
  محاسبه **نمی‌شود**
- ریسک دستی کاربر: `RiskBasis = manual_risk`
- **کمیسیون و سواپ** از PnL تحقق‌یافته **کسر می‌شود**
- چند خروجی: PnL خالص کل تقسیم بر ریسک اولیه
- `ExitLegR` ممکن است به‌ازای هر خروج محاسبه شود، اما `TradeR`
  بر مبنای **نتیجه کل** است
- فیلدهای MAE/MFE در نسخه ۱ **رزرو** و در نسخه ۳ فعال می‌شوند
