# بنچمارک‌های عملکرد

> وضعیت: فاز ۰ — اهداف قابل تست.

## اهداف

| سناریو | هدف |
|---|---|
| راه‌اندازی اپلیکیشن | زیر ۲–۳ ثانیه |
| داشبورد با حافظه نهان | P50 < 150 ms، P95 < 300 ms |
| ذخیره معامله فنی | P95 < 300 ms |
| ثبت سریع معامله | P95 < 15 ثانیه |
| ثبت کامل معامله | P95 < 60 ثانیه |
| فیلتر ساده | P95 < 500 ms |
| فیلتر ترکیبی | P95 < 800 ms |
| لیست معاملات با ۱۰۰٬۰۰۰ رکورد مصنوعی | قابل استفاده باقی بماند |
| واردات ۱۰۰۰ رکورد | زیر ۱۰ ثانیه |
| پشتیبان‌گیری کامل | زیر ۳۰ ثانیه |
| بازیابی کامل | زیر ۶۰ ثانیه |
