# مدل اجرا

> وضعیت: فاز ۰ — ساختار اولیه.

## فرایندها

1. **فرایند اصلی (کرنل)** — Rust + Tauri 2؛ شامل همه موتورها
2. **فرایند‌های پلاگین (Sidecar)** — پلاگین‌های نصب‌شده؛ JSON-RPC 2.0 روی stdio
3. **سایدکارهای پایتون** — پلاگین‌های تحلیلی؛ venv اختصاصی هر پلاگین

## پروتکل ارتباطی

- JSON-RPC 2.0 با پیام‌های خط‌محور (newline-delimited)
- حداکثر اندازه پیام: ۱۰ مگابایت
- تایم‌اوت پیش‌فرض: ۳۰ ثانیه
- احراز هویت با نشانه نشست (session token)

## ترتیب راه‌اندازی (نسخه ۱)

1. بارگذاری پیکربندی کرنل
2. باز کردن دیتابیس رمزنگاری‌شده (پس از باز کردن قفل با رمز عبور)
3. اجرای مهاجرت‌ها
4. بارگذاری مانیفست پلاگین‌ها و راه‌اندازی پلاگین‌های فعال
5. آماده‌سازی پوسته رابط کاربری
