# مدل امنیت

> وضعیت: فاز ۰ — ساختار اولیه.

## پایه‌ها

- هش رمز عبور: Argon2id
- مشتق‌سازی کلید: KDF از رمز عبور کاربر
- رمزنگاری: AES-GCM
- بهداشت حافظه: zeroize و secrecy
- رمزنگاری دیتابیس: SQLite سازگار با SQLCipher
- رمزنگاری پشتیبان: همان مدل حفاظت دیتابیس
- لاگ حسابرسی برای عملیات حساس

## قوانین سخت‌گیرانه

- قفل خودکار باید دسترسی به کلیدهای فعال را قطع کند، نه فقط رابط کاربری را مخفی کند.
- بازیابی رمز عبور فراموش‌شده غیرممکن است؛ کاربر باید هشدار ببیند.
- پلاگین‌ها هرگز به کلیدها دسترسی ندارند.
- هیچ داده کاربری به سرور خارجی ارسال نمی‌شود (آفلاین-فرست).
- لاگ‌ها حاوی رمز عبور یا بارهای مالی کامل کاربر نمی‌شوند.
