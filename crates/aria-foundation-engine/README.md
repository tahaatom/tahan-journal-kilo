# aria-foundation-engine

موتور پایه کرنل آریا: مدل خطا، شناسه‌ها، زمان، پیکربندی و لاگ.

## وضعیت

فاز ۱.۱ — پیاده‌سازی کامل. مستقل کامپایل می‌شود و هیچ منطق کسب‌وکار موتور دیگری را پیاده نمی‌کند.

## ماژول‌ها

| ماژول | محتوا |
|---|---|
| `error` | مدل خطای ساختاریافته با thiserror: کد عددی یکتا (۱۰۰۱–۱۰۱۱)، متغیر ماشین‌خوان، کلید پیام فارسی، متنیان JSON و خطای منبع |
| `ids` | ۱۳ شناسه تایپ‌شده (ProfileId تا CommandId) روی UUID v4 با سریالیزه‌سازی شفاف |
| `jalali` | تبدیل و قالب‌بندی جلالی، نام ماه/روهفته، ارقام فارسی |
| `time` | سرویس زمان با ذخیره UTC/ISO 8601، نمایش جلالی، نشست‌های معاملاتی (ساعت تهران) |
| `config` | `KernelConfig` با ۹ فیلد، مسیرهای استاندارد از `dirs`، بارگذاری/ذخیره JSON |
| `logging` | لاگ محلی با tracing: خروجی استاندارد + فایل چرخشی روزانه |

## وابستگی

سطح ۰ — هیچ وابستگی به موتور دیگری ندارد.

## تست

```powershell
cargo test -p aria-foundation-engine
```

تست‌ها شامل: یکتایی شناسه‌ها، یکتایی کدهای خطا، تبدیل زمان/جلالی، بارگذاری/ذخیره پیکربندی، رفتار خطاهای مسیر، و مقداردهی لاگ با نوشتن رویداد ساختاریافته در فایل محلی.
